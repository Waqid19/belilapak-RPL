# BeliLapak

BeliLapak adalah aplikasi e-commerce yang menjual berbagai produk fashion seperti kaos, celana, tas, sepatu, dan produk outfit lainnya.

## Mata Kuliah
Proyek Perangkat Lunak (PPL)

## Anggota Kelompok
1. Nama Anggota 1 - Product Owner
2. Nama Anggota 2 - Scrum Master
3. Nama Anggota 3 - UI/UX Designer
4. Nama Anggota 4 - Frontend Developer
5. Nama Anggota 5 - Backend Developer
6. Nama Anggota 6 - QA / Tester
7. Nama Anggota 7 - Dokumentasi & Branding

## Fitur Utama
- Pengelolaan produk
- Katalog produk
- Keranjang belanja
- Checkout
- Pembayaran
- Perhitungan ongkos kirim
- Status pesanan
- Fitur komputasional sederhana
